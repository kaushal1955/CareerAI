# CareerAI Database

## Current collections implemented

### Users
Application-level user records synced from Clerk.

### Profiles
Onboarding and career profile data.

### Resumes
Uploaded resume metadata, extracted text, storage info, and analysis output.

### BuiltResumes
Structured resume builder drafts for PDF export.

### CareerRecommendations
Generated recommendation snapshots based on profile and resume signals.

### SkillGaps
Stores target career, current skills, missing skills, course suggestions, projects, and learning priorities.

### Roadmaps
Stores staged learning plans with week ranges, topics, practice items, projects, and milestones.

### Interviews
Stores generated mock interview sessions, answers, scores, strengths, weak areas, and improvement suggestions.

### Mentors
Stores mentor profile details, expertise, availability, assigned students, and summary counters.

### MentorSessions
Stores mentor-student scheduled guidance sessions, provider info, duration, join instructions, status, notes, and feedback.

### MentorResources
Stores resources shared by mentors for all assigned students or a specific student, including moderation state.

### Chats
Stores mentor-student message history for in-app chat.

### Notifications
Stores user notifications for chat, assignments, sessions, resources, admin updates, and more.

### Reports
Stores user-submitted issue/moderation reports and admin review state.
